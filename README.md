:::Overview
APZX SPOOFER X is a Windows-based, keyboard-driven command-center
project in the APZXCORE ecosystem. It brings its available utilities
together in a compact console interface with a distinctive
electric-cobalt visual style.

The interface is designed around quick navigation, clear status
indicators, and a focused workflow. Actual capabilities depend on the
features implemented in the version you have installed.
Important: This is an unofficial third-party project and is not
affiliated with or endorsed by Discord. It cannot grant official
Discord staff, partner, or other restricted badges. Automated activity
manipulation or use of private endpoints may violate Discord's terms
and can put an account at risk.

Setup
Requirements
- Windows 10 or Windows 11
- Python 3.10 or newer, if running from source
- The project files from a trusted source
Run from source
1. Download or clone the repository.
2. Open a terminal in the project directory.
3. Run the application using the entry-point file included in your
   release. For example:
   python spoofer.py
   If your release includes a launch.bat file, you can also run that
   file.
The entry-point filename may differ between releases. Use the filename
included in your actual project folder.
Navigation
  Key         Action
  ↑ / ↓   Move through menu items
  Enter     Select the highlighted item
  1–7       Use a numbered shortcut, where supported
  Esc       Return or exit, where supported

Troubleshooting
The application closes immediately - Run it from PowerShell or
Command Prompt so you can read any error output. - Confirm that the
required Python version is installed. - Check the release notes for
additional dependencies or setup steps.

The preview image is missing - Confirm that assets/preview.png
exists and is committed to the repository. - Ensure the filename and
capitalization match the image path in this README.

A feature is unavailable - Confirm that you are using the expected
release and review its documentation. - Report reproducible issues
through the repository's issue tracker. Do not include tokens, cookies,
or other secrets in reports.
